# Proponer una explicación del PIN de cuatro dígitos para el manual

## Contexto y propósito

El formulario incluye la sección «Tu PIN secreto de sembrador (4 dígitos)», pero el manual compartido no explica este paso. Una persona que siga únicamente el manual podría desconocer cómo elegirlo y por qué debe guardarlo.

Este issue —una conversación de GitHub para documentar una tarea— busca una propuesta breve que el administrador pueda revisar e incorporar al manual.

## Tarea delimitada

Escribe en un comentario de este issue un párrafo con el título «Elige y guarda tu PIN». Debe explicar cómo escribir cuatro dígitos o usar «Generar PIN aleatorio» y recordar que el PIN debe guardarse de forma privada.

Al explicar su uso posterior, atribuye la información al formulario: este indica que sirve para identificarse como sembrador, agregar fotos de seguimiento y descargar el certificado. El funcionamiento de esas acciones sigue pendiente de verificar.

La entrega es el texto propuesto. No requiere programar, editar el PDF ni entrar al panel administrativo. La incorporación al manual queda a cargo del administrador.
